Privacy Policy

MH Sangha Mailer is a private tool used only by its operator to send the MH Sangha newsletter.

With the operator's permission, it reads one Gmail mailbox that the operator owns, only to find newsletter content and approval replies. It marks handled messages as read. It does not send email through Gmail, and it does not share, sell, or transfer Gmail data to anyone. Gmail data is used only for this purpose and is not used for advertising or to train AI models.

Data is stored only on the operator's private server and is kept only as long as needed to send each week's newsletter.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
